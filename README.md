Food Delivery App 🍔🚚A full-featured, cross-platform Food Delivery Application built using Flutter and powered by Firebase (or backend APIs). This project provides a complete end-to-end architecture covering customer food ordering, restaurant management, and real-time delivery tracking.🚀 Key FeaturesAuthentication System: Secure user registration, email/password login, and session management via Firebase Auth.Dynamic Menu & Restaurant Browsing: Explore nearby restaurants, filter categories, view detailed food items, options, and descriptions.Interactive Cart & Checkout: Add, modify, or remove items, calculate total pricing dynamically, and manage order summaries.Payment Integration: Secure card payment modules and digital checkout options.Real-Time Order Tracking: Live order status tracking (Placed $\rightarrow$ Preparing $\rightarrow$ Out for Delivery $\rightarrow$ Delivered) with integrated map routing.Dark & Light Mode UI: Fully customizable theme preferences built with clean, modern Flutter widgets.🛠️ Tech StackFrontend: Flutter (Dart)Backend / Database: Firebase Firestore / Realtime DatabaseState Management: Provider / Bloc / RiverpodLocation & Maps: Google Maps SDK & Geolocator
